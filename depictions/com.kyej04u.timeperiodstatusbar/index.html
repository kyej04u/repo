TimePeriodStatusBar

Version 1.0.5 · iOS 6.0–6.1.x · Tweaks

說明

在 iOS 6 狀態列顯示更細的時段，像 iPadOS 16+ 一樣：午夜 / 凌晨 / 清晨 / 上午 / 中午 / 下午 / 傍晚 / 晚上，例如「上午 3:07」→「凌晨 3:07」。只在 12 小時制、中文語系時啟用；英文 AM/PM 不動。

0:00–0:59午夜
1:00–4:59凌晨
5:00–7:59清晨
8:00–10:59上午
11:00–12:59中午
13:00–16:59下午
17:00–18:59傍晚
19:00–23:59晚上

這是 debug 版本，會寫 log 到 /var/mobile/TimePeriodStatusBar.log、/tmp/TimePeriodStatusBar.log 和 /var/log/TimePeriodStatusBar.log。

Description

Show a finer time-of-day period in the iOS 6 status bar, like iPadOS 16+. Only active in 12-hour time, Chinese locale only; English AM/PM is left unchanged. v1.0.5: also applies inside apps (injects into UIKit processes, not SpringBoard only). DEBUG build: no longer links CydiaSubstrate (uses ObjC runtime swizzling instead, so it loads on old iOS 6 Substrate too); writes a log to /var/mobile/TimePeriodStatusBar.log, /tmp/TimePeriodStatusBar.log and /var/log/TimePeriodStatusBar.log (detailed logs only in SpringBoard; other processes log one load line).
