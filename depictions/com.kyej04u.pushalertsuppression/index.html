PushAlertSuppression

Version 1.0.0 · iOS 4–6 · Tweaks

說明

隱藏 iPhone 未正確啟用造成的「連接iTunes以接收"推播通知"」提示， 支援iOS 4-6

此插件只隱藏這個提示，不會修復推播通知本身

Description

Hide the "Connect to iTunes to Use Push Notifications" prompt caused by an iPhone that is not properly activated. Supports iOS 4-6.

This tweak only hides the prompt; it does not fix push notifications themselves.
